# 公開設定とコメント受付

エディタ右上の公開状態を押すと、公開範囲、タグ、翻訳、コメント受付、閲覧リンクをまとめて確認・変更できる。メニューは公開範囲から始まり、その直後にタグを表示する。「公開設定」の見出しは表示しない。

閲覧リンクは既存の「プレビュー」を使用し、公開状態にかかわらず同じ名前で表示する。

## 保存と公開

Webではタイトルと本文を一つの編集面で入力する。先頭のタイトルはH1固定で、本文の書式メニュー・画像・ブロックの並べ替えの対象にはしない。タイトルでReturnまたはShift+Returnを押すと、タイトルを分割せず既存本文の先頭へ移る。日本語の変換確定中は移動しない。

タイトルと本文の変更は同じ自動保存へ送るが、保存データは従来どおりタイトルとMarkdown本文に分け、タイトルを本文へ混ぜない。空白だけのタイトルは小文字の `untitled` で保存する。

タイトルと本文をまたぐ選択の削除・貼り付けでも、選択外の本文と書式をタイトルへ取り込まない。本文だけを全文選択して貼り替える場合は、タイトルを残して本文を置き換える。

- 自分のみ：所有者だけが閲覧できる。
- 公開中：誰でも閲覧でき、本文やタイトルの保存内容がそのまま公開ページへ反映される。
- 公開時と「翻訳する」を押したときは、選択言語と翻訳コンテキストを既存の翻訳処理へ渡す。
- 未保存の変更がある間は公開と翻訳を待ち、保存した本文を対象にする。

## タグ

タグは公開メニューで追加・削除する。既存のタグ候補から選択するか、名前を入力してEnterで追加できる。最大5個、各1〜15文字で、記号・空白は使えない。

変更は本文の保存と独立して既存のタグ更新APIへ送信する。メニューを閉じても追加・削除したタグと保存中の状態は保持し、閉じたままでも保存は完了する。保存に失敗した場合は入力したタグとエラーを保持し、メニューを再表示して保存を再試行できる。タグの保存中は追加・削除を無効にして二重送信を防ぐ。

## コメント受付

初期値はON。既存の記事にもONを適用する。

OFFにすると、新規コメントと返信を受け付けない。既存コメントの本文・返信・記事全体のコメント件数は引き続き表示し、本人による既存コメントの更新・削除も許可する。古い画面からの投稿もAPIで拒否する。再びONにすると投稿と返信を再開できる。

`POST /api/reader-actions?action=pageComments`へ`{ pageId, enabled, locale }`を送る。ログイン中の所有者だけが変更でき、アーカイブ済み記事は変更できない。成功時は`data.commentsEnabled`へ保存した真偽値を返す。本文・公開状態・日時・翻訳ジョブは変更しない。

コメント取得APIと閲覧HTMLには受付状態を反映する。設定変更は既存の配信キャッシュ無効化経路を使い、記事を更新対象にする。読者画面を先に切り替える間、旧Gatewayが受付状態を返さない場合はONとして扱う。

Markdown一括書き出しでは、frontmatterの`comments_enabled`に設定を保存する。
